# Production Line Bottleneck Analysis & Productivity Improvement

## 📌 Project Overview

This project analyzes automotive manufacturing-line performance to identify production bottlenecks, cycle-time constraints, downtime losses, and opportunities for productivity improvement.

The analysis uses Python for data cleaning and analysis, Excel for structured analysis, Power BI for visualization, and Lean Manufacturing concepts such as takt time, bottleneck analysis, OEE, Pareto analysis, and cycle-time improvement.

> **Note:** The dataset used in this project is synthetic and is intended for analytical and portfolio purposes. The improvement scenarios are simulations and do not represent actual factory implementation results.

---

## 🎯 Objectives

- Identify production-line bottlenecks
- Compare takt time with actual and bottleneck cycle time
- Identify lines operating above required takt time
- Analyze OEE and its major loss factors
- Analyze downtime patterns using Pareto analysis
- Evaluate production throughput and productivity
- Identify potential improvement opportunities
- Simulate the impact of bottleneck cycle-time reduction
- Build an interactive Power BI dashboard for manufacturing KPIs

---

## 📊 Dataset

The project uses the **MFG-005 Synthetic Manufacturing Line Performance Dataset**.

The dataset contains shift-level manufacturing-line performance data covering areas such as:

- Line and station information
- Takt time
- Actual cycle time
- Bottleneck cycle time
- Production quantity
- Throughput
- OEE
- Downtime
- MTBF and MTTR
- Changeover performance
- Quality metrics
- Equipment and operator metrics
- Energy and cost-related metrics

The original dataset contains **3,000 records and 118 columns**. The automotive subset contains **660 records**.

The dataset is synthetic and should not be interpreted as real factory production data.
